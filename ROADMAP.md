# Roadmap

This document outlines the strategic vision and upcoming features for **Pathlight.ai**.

## Current Focus (v0.1.x)
- Stabilizing the unified FastAPI backend.
- Improving PDF generation formatting.
- Ensuring robust Redis & Celery job queues under load.

## Short-term Goals (v0.2.x)
- **Local LLM Support:** Add robust support for Ollama and local execution of models to reduce API costs.
- **Enhanced ATS Scoring:** Refine the proprietary ATS scoring algorithm with deeper TF-IDF matching and structural analysis.
- **Multi-language Resumes:** Allow tailoring and PDF export in languages other than English (e.g., Spanish, French).

## Medium-term Goals (v0.3.x - v0.5.x)
- **Chrome Extension Automation:** Implement automated form-filling for job applications directly from the extension.
- **Agentic Workflows:** Implement a fully autonomous agent that can browse job boards, score jobs against a Master Profile, and automatically queue tailoring jobs.
- **Enhanced Dashboard:** Advanced analytics on interview callback rates vs ATS scores.

## Long-term Vision (v1.0.0+)
- **Enterprise / B2B Tier:** Career center integrations for universities and coding bootcamps to track cohort success.
- **Interview Prep Agents:** Use the tailored resume + job description to spin up an interactive voice agent that conducts a mock interview tailored to the specific role.

*Note: This roadmap is subject to change based on community feedback and contributions.*
