# Security Policy

## Supported Versions

Pathlight.ai is under active development. Currently, only the `main` branch is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| >= 0.1.x| :white_check_mark: |
| < 0.1.x | :x:                |

## Reporting a Vulnerability

We take the security of Pathlight.ai seriously. If you discover a security vulnerability, please do NOT report it by opening a GitHub issue. Instead, please follow these steps:

1. Draft a GitHub Security Advisory in the repository, or email the maintainers directly.
2. Provide a detailed description of the vulnerability, including steps to reproduce.
3. Allow up to 48 hours for the maintainers to acknowledge your report.
4. We will work with you to understand the impact, develop a fix, and coordinate a public disclosure if necessary.

Thank you for helping keep the open-source community safe!
